# 游戏策划全流程设计（完整参考）

本文件保留完整方法论正文，供需要细节时阅读。日常执行以 `SKILL.md` 为准。

## 一、游戏策划的九大职能分工

### 1. 系统策划 —— 框架建筑师
负责游戏整体框架、功能入口及 UI 界面的设计。核心工作包括：大厅布局规划、商城入口设计、模式选择架构的层级化布局。要求具备功能分区思维——在有限屏幕空间内，基于玩家行为路径合理安排商业入口与核心玩法入口的布局优先级，实现商业化与游戏体验的平衡。

### 2. 玩法策划 —— 乐趣定义者
定义游戏的核心规则与体验，构建玩家交互框架。设计工作围绕三个核心要素展开：
- **核心行动**：玩家在游戏中最主要和最频繁的操作（如射击、跳跃、建造）
- **目标与挑战**：为核心行动设定障碍和目标，创造"心流"体验——挑战难度需循环交替压力释放与强度爬升，精准匹配玩家操作水平
- **反馈与回应**：玩家完成行动后游戏世界给予的即时反馈，是产生微小精神奖励的关键

玩法设计的本质是激活大脑的奖励回路：多巴胺对应奖励期待感（装备掉落音效、进度条即将满格时的兴奋），内啡肽绑定克服挑战后的成就感（逆风翻盘），血清素关联社交认同和成长自豪感（排行榜、虚拟资产积累）。

### 3. 战斗策划 —— 操作体验雕刻师
负责构建核心战斗操作和交互机制，分为三类：
- **框架型**：宏观设计战斗系统和玩法模式，确定游戏调性（MOBA 的 5v5 对抗、FPS 的枪战节奏）
- **内容型**：设计具体角色、怪物、Boss 等可玩内容，包括角色背景研究、核心玩法机制（如多武器切换）、动作风格与特效方向
- **流程型**：优化技术流程，提升团队生产效率

核心工作要点：
- **3C 设计**（Character, Control, Camera）：角色移动、镜头控制、技能释放的基础操作体验
- **动作设计验收四维度**：可信度（符合物理规律和人类经验）、风格化（统一的美学表达）、印象感（独特动作强化 IP 记忆点）、细节（关键帧的时空节点控制非匀速动作曲线）
- **打击感四原则**：可信度（基础物理反馈符合预期）、夸张化（艺术加工增强冲击力）、风格化（统一美学）、个性化（角色特质表达）
- **关键帧拆分**：攻击动作分解为前摇、伤害帧、保持帧、后摇——前摇需及时反馈，保持帧需视觉余韵，后摇可交由美术发挥

### 4. 数值策划 —— 经济系统规划师
负责设计和计算游戏内的各项数值，保障游戏整体体验。数值策划是容错率最低的岗位——一个零的误差可能导致经济系统崩溃。

**五大核心数值模块**：
- **经济数值**：掌控游戏内资源的产出、消耗、流转循环（如 SLG 中农田每小时产粮→士兵消耗粮草→士兵保护伐木场→木材建造更多农田）
- **养成数值**：从深度（总培养成本）、收益（性价比梯度，如 1 元兑换 20-50 战力差异）、投放（每日资源投放量平衡商业化与体验）三个维度设计
- **战斗数值**：底层公式设计（加减乘除的选择匹配游戏类型）、数值模型搭建、具体数值分配、平衡性调整、PVE 心流体验调控
- **生态数值**：控制游戏整体节奏——模块解锁时间、地图开放节奏、资源与城市分布比例
- **玩法数值**：为具体玩法提供数值支撑，如联盟参战人数、建筑积分增速、战斗时长、兵力上限与战损比例

**八项核心能力**：游戏理解（广度+深度）、数学知识（代数/函数/概率/统计）、用户心理（挑战欲激发、递进式成就感）、逻辑思维（层层溯源推导）、结构化思维（模块拆解+关联梳理+参数预留）、沟通表达、细致谨慎（职业底线）、持续学习（Excel→Python→SQL 工具链进阶）。

### 5. 关卡策划 —— 体验建筑师
是游戏世界的建筑师、玩家情绪的导演、游乐园体验的设计师。负责设计关卡的空间结构、节奏、视觉体验和玩法乐趣。

**设计流程**：
1. **创意规划**：确定核心创意点，进行题材、玩法和技术创新的头脑风暴
2. **空间分区**：将关卡划分为缓冲区、对抗区等功能区域，赋予主题概念
3. **动线设计**：针对猛攻型、保守型、刺客类等不同玩家类型设计差异化动线和策略空间
4. **白模搭建**：确定尺寸，用 SketchUp 等工具搭建三维白模验证空间关系
5. **美术替换**：与美术紧密合作，确保视觉引导、氛围营造和构图呈现符合玩法需求
6. **迭代优化**：上线后持续收集玩家反馈和数据进行复盘优化

设计手法示例：利用《艾尔登法环》西弗拉河式的空间反差——2 分钟压抑的电梯密闭空间后突然展开壮阔场景，形成强烈的情绪张力。关卡策划本质是用动线设计放大美术构图，将静态画面转化为高光记忆点。

### 6. 文案策划 —— 灵魂赋予者
角色定位为游戏世界的"首席装修师"和"灵魂赋予者"——既要"写说明书"（清晰说明游戏规则、功能），更要"注入灵魂"（通过故事、背景让玩家产生情感共鸣）。

**四大基础工作**：
- **世界观构架**：设计七个核心部分——起源、地理风貌、种族、生物、阵营、人物、大事件编年史
- **叙事设计**：根据游戏特性选择叙事方式——碎片化叙事（如《艾尔登法环》通过环境细节激发探索欲）或线性叙事（如《巫师3》将平淡流程转化为戏剧性体验）
- **角色塑造**：创造有背景故事、鲜明性格和独特台词的鲜活角色（如《英雄联盟》烬——病态优雅的台词与独特换弹机制高度统一）
- **文本落地**：遵循三大标准——清晰准确、保持一致性、契合世界观语境

**核心价值**：赋予玩法意义（将机械的"打 Boss"转化为具有道德困境的叙事体验）、铸造 IP 核心价值（如王者荣耀"长安赛年"通过连续叙事将地理概念升华为有血有肉的 IP 符号）、驱动情感共鸣（让玩家为角色命运欢笑或落泪）。

### 7. 技术策划 —— 管线建筑师
核心职责是设计和优化游戏内容的生产流程（即"管线"），目标是"更高效地生产内容"而非直接"生产更好的内容"。

**核心价值**：通过设计工具和规范，将"作坊式"的生产模式转变为"工厂式"的流水线模式。技术策划是策划与程序之间的"多语种翻译"——既能精准理解策划需求，又能用技术能力快速评估可行性，在需求进入程序前增加原型验证阶段，以最低成本完成性价比评估和风险过滤。

**工作流程**：需求分析 → 评估实现路径与成本 → 设计并落地原型 → 组织试用与迭代 → 交付正式功能及配套文档。

**核心能力**：游戏设计理解能力、内容生产能力、广泛的游戏开发技术知识（引擎/渲染/物理/动画）、代码读写能力、以及最重要的——"利他心"：致力于让所有创意和协作过程都更顺畅。

### 8. 世界观架构师 —— IP 铸造者
负责构建游戏世界的底层逻辑，并围绕 IP 的三大核心标准进行创作：

**IP 三大标准**：
- **内容性**：IP 需具备可复用的、跨越领域的丰富内容
- **确定性**：IP 需要有明确的边界和辨识度，能让受众一眼认出
- **情感性**：IP 最核心的标准是能够激发受众的特定情绪反馈，形成有忠诚度的粉丝群体

**四大创作锦囊**：
- **以核心人物决定故事方向**：人永远比事更重要——即使故事细节模糊，鲜明的人物形象仍能长久留存于受众心中
- **以导演思维呈现完整情节**：世界观策划需扮演"导演"角色，统筹协调各方资源，善用环境叙事（玩家自行从空间细节拼凑故事）和涌现性叙事（玩家自主探索产生的故事）
- **以全局视野规划更新节奏**：借鉴美剧的"封闭与开放并行"模式或漫威的"部为节点"模式，制定可持续的内容更新策略
- **以衍生内容补充官方内容**：主动构建和引导同人圈，官方产能永远无法满足用户需求，活跃的同人创作能有效填补空白

### 9. 核心策划 / 主策划 / 制作人 —— 总设计师
负责将各类策划工作串联整合，把控全局。需要具备市场敏锐度、跨职能协调能力，能快速组建专项小组、高效推进项目进度。

## 二、核心设计方法论

### KES 设计法
从核心创意到完整游戏的系统化设计方法：
- **K（Key Point 核心点）**：游戏最闪亮、最独特的亮点，是设计的北极星和团队共识。不局限于单一模块，可以是核心行动、目标挑战或反馈体验。核心点需像电梯原理一样能快速传达价值，统一团队决策标准
- **E（Expand 扩展）**：基于核心点进行严谨的逻辑推演，自上而下构建完整的游戏世界和各系统（PVE/PVP、成长、社交等）。设计需灵活调整，研发成本和标准必须明确
- **S（Standard 标准）**：对设计方案进行归纳总结，明确研发成本、技术标准和实现方式

### 游戏设计的核心循环
游戏好玩的核心在于通过虚拟与现实的连接，模拟并触发人类远古时期的行为模式（如捕猎成功），激活大脑的奖励回路：
1. 核心行动（玩家最主要的行为）
2. 目标与挑战（为行动设定障碍，创造心流）
3. 反馈与回应（即时反馈产生微小精神奖励）

## 三、策划案撰写规范

### 核心原则
策划案需具备**清晰、准确、可执行**三大特点，是确保策划想法能被团队理解和落地的关键工具。

### 撰写结构
- **标题**：简洁明了，直接传递核心意图（如"优化小地图功能"而非模糊的"地图相关改动"）
- **迭代记录**：记录版本修改的历史，便于复盘和同步信息
- **需求背景与概述**：用 200-300 字讲清"为什么做"和"怎么做"，确保所有合作方方向一致
- **详细描述**：采用总分式分类拆解功能模块，配以文字、流程图、参考图等多种形式说明。避免模糊表述导致开发团队理解偏差
- **备注**：列出未完待续之处、风险点、关联资源或分工，方便开发跟进

### 策划核心工作流程
发现需求 → 思考设计 → 方案完善 → 落地执行。需求来源包括：老板突发奇想、玩家负面反馈、自我发现的设计缺陷。关键是将需求转化为可行方案时，要精准拆解需求本质，避免用战术勤奋掩盖战略懒惰。

### 协作要点
- 需求传达需清晰完整——模糊需求将导致大量返工（如未说明皮肤品阶和用途，美术按最高标准设计后发现只是活跃奖励）
- 分阶段验收：将大目标拆解为小里程碑，每周验收阶段性成果
- 方案更新需同步所有合作方，避免信息不对称
- 与开发沟通时分两步：先用清晰框架描述需求本质，再信任开发团队的专业性避免微观管理

## 四、策划核心能力模型

### 硬实力
- **游戏理解能力**：深入拆解经典游戏的设计思路——系统、关卡、数值、叙事四个方面
- **跨学科知识体系**：从技术工具（Excel/Python/SQL/游戏引擎）到人文历史、心理学、神经科学
- **动手实践能力**：用游戏引擎制作 Demo 验证设计想法，形成个人作品集
- **数据分析能力**：从表层统计到深层体验分析的双重洞察力

### 软实力
- **用户为本**：从"自我喜好"转变为"用户视角"思考问题——这是最核心的思维转换
- **落地执行**：理解程序和美术的工作流程，确保设计方案能真实落地，而非停留在"梦想家"阶段
- **沟通表达**：作为需求发起人，需精准传递设计逻辑，避免因理解偏差导致的返工
- **坚韧不拔**：在高频次迭代中保持稳定输出和高质量内容
- **细致谨慎**：数值错误具有隐蔽性、破坏性和高昂修复成本，是安身立命的根基
- **源于热爱**：保持对游戏的热爱，持续学习新趋势

### 成长路径
执行策划（负责聊天系统等基础功能）→ 模块负责人（独立负责小型模块设计）→ 核心策划（独立主导系统设计）→ 制作人（统筹全局，把控全流程）

## 五、AI 时代的游戏策划

AI 正在重塑游戏策划的工作模式——从单一文本创作扩展到全流程创意生产（分镜、语音、动捕等环节的 AI 协同）。但核心的创意、深刻的情感、宏大的架构以及与玩法的深度融合，仍需人类的智慧和审美。AI 本质上是能力解放而非替代，策划应主动学习和掌握 AI 工具，将精力聚焦于更高价值的创意决策。
