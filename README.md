# 🦪 剝蚵仔模擬器

> 夜市巷口、一盆蚵仔、三個阿婆，看誰剝得最快！

## [▶ 馬上開玩](https://jinweihuang20.github.io/oyster-sim/)

手機、電腦都能玩，打開瀏覽器就上工。

---

夜深了，巷子裡的蚵寮還亮著燈。你拉張小板凳坐下，旁邊幾位阿婆手裡的蚵刀沒停過，嘴裡也沒停過。
一顆顆蚵仔等著你找縫、下刀、撬開，再把肉丟進臉盆。剝得快就有錢賺，手太慢可是會被唸的。
偶爾蚵殼裡還藏著珍珠……或是一些奇怪的東西。

## ✨ 特色

- 🔪 **剝蚵手感**：看準殼縫下刀，抓好時機把殼撬開，太大力殼會碎掉
- 🎯 **投肉入碗**：瞄準藍色臉盆，按住蓄力，在藍區放開，完美出手還有加價
- 🥷 **攻防對決**：趁阿婆不注意偷她的蚵仔，但被抓到她可是會丟殼報仇，記得撐傘擋！
- 📖 **圖鑑收集**：白、粉、金、黑珍珠，還有假牙、古早硬幣、金戒指等怪東西
- 🏪 **雜貨店**：買刀具、臉盆、雨傘、老花眼鏡、藥品，打造專屬裝備
- 📍 **各地蚵寮**：入碗數達標就自動解鎖王功、東石、布袋，工錢更高，阿婆更兇
- 🌙 **夜班加成**：晚上上工，收入 +20%
- ⏱ **臨時工**：沒空？來個 1 分鐘或 2 分鐘的短班
- 📻 **收音機**：放一段懷舊老歌陪你剝蚵
- ✏️ **自訂名字**：在設定裡取個響亮的名號，爭奪「今日剝蚵冠軍」

## 🎮 怎麼玩

- **手機**：點按鈕操作，在畫面中央滑動來撬殼；投肉時按住蓄力、放開投出
- **電腦**：用滑鼠操作，按住蓄力、放開投出
- 第一次玩會有教學，跟著做就會了

## 💡 小訣竅

- 前幾班有新手保護，蚵仔比較好剝，趁機多存點錢
- 戴上老花眼鏡，殼縫看得更清楚
- 不要一直偷，阿婆生氣了會一直丟殼
- 完美出手每次多 $2，練好準度很划算

## 🛠 技術

Three.js + Vite + TypeScript。音效全部用 WebAudio 即時合成，無外部音檔。存檔使用 localStorage。

## 本機開發

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 打包到 dist/
```
